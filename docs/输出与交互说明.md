# 输出与交互说明

本文档说明编译器控制台输出的阶段顺序与分段查看方式。

## 输出顺序

程序按以下顺序输出：

1. `===== 词法分析 =====`
   - 输出全部 token。
2. `===== 表达式分析表构建 =====`
   - 自动构建并输出表达式文法的 SELECT 集、LR(1) ACTION 表、GOTO 表。
3. `===== 语法分析 =====`
   - 输出递归下降语法分析日志与最终通过/失败信息。
4. `===== 四元式输出 =====`
   - 输出语义动作生成的四元式序列。
5. `===== 四元式优化 =====`
   - 在四元式输出后、目标代码生成前执行四元式优化，并输出优化后的四元式序列。
6. `===== 活跃信息标记 =====`
   - 基于优化后的四元式与基本块信息生成活跃变量标记结果并输出。
7. `===== 目标代码生成 =====`
   - 基于优化后的四元式生成目标代码并输出。

> 表达式分析表现在在“词法分析完成后”立即构建和展示，不再等到首次进入 `〈表达式〉` 规则时才输出。

## 分段输出（按回车继续）

为便于查看，控制台大段文本采用分页输出：

- 每段固定行数后暂停（当前为 30 行）。
- 提示：`[按回车继续下一段]`
- 用户按回车后继续输出下一段。

分页适用于：

- token 列表
- 表达式 SELECT/LR(1) 分析表
- 语法分析日志
- 四元式输出
- 四元式优化输出
- 活跃信息标记输出
- 目标代码输出

## 非交互场景

当标准输入不是终端（例如重定向、管道、CI）时，程序不会等待回车，会一次性输出全部内容，避免阻塞。

## GUI 版本（Node/Electron）

项目新增基于 Node/Electron 的 GUI：

1. 先编译命令行版：
   - `cmake -S . -B build`
   - `cmake --build build`
2. 安装 GUI 依赖并启动：
   - `cd gui-node`
   - `npm install`
   - `npm start`

说明：

- GUI 提供源文件选择、运行编译按钮与分区输出视图，对应各阶段输出内容。
- 输出文件仍会保存在源文件同目录，可在 “输出文件” 页签查看具体路径。
- 默认从 `../build/NEUcompiler` 调用编译器；如路径不同，可设置环境变量 `NEUCOMPILER_BIN` 指向可执行文件。
