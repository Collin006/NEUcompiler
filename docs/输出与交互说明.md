# 输出与交互说明

本文档说明编译器控制台输出的阶段顺序与分段查看方式。

## 输出顺序

程序按以下顺序输出：

1. `===== 词法分析 =====`
   - 输出全部 token。
2. `===== 表达式分析表构建 =====`
   - 自动构建并输出表达式文法的 SELECT 集、LR(1) ACTION 表、GOTO 表。
3. `===== 语法分析 =====`
   - 输出递归下降语法分析日志与最终通过/失败信息。
4. `===== 四元式输出 =====`
   - 输出语义动作生成的四元式序列。

> 表达式分析表现在在“词法分析完成后”立即构建和展示，不再等到首次进入 `〈表达式〉` 规则时才输出。

## 分段输出（按回车继续）

为便于查看，控制台大段文本采用分页输出：

- 每段固定行数后暂停（当前为 30 行）。
- 提示：`[按回车继续下一段]`
- 用户按回车后继续输出下一段。

分页适用于：

- token 列表
- 表达式 SELECT/LR(1) 分析表
- 语法分析日志
- 四元式输出

## 非交互场景

当标准输入不是终端（例如重定向、管道、CI）时，程序不会等待回车，会一次性输出全部内容，避免阻塞。
