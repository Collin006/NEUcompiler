# Pascal 翻译文法（含语义动作）

本文档基于 `docs/文法.md`，在产生式后加入语义动作，目标为：

1. 维护符号表（`SYNBL/TYPEL/PFINFL`）
2. 生成四元式序列（`(op, arg1, arg2, result)`）

---

## 约定

- `emit(op, a1, a2, r)`：生成四元式，返回序号。
- `newtemp()`：生成临时变量名。
- `backpatch(i, t)`：把第 `i` 条四元式的 `result` 回填为目标地址 `t`。
- `nextquad`：下一条四元式序号。
- `E.place`：表达式 `E` 的结果位置。
- `ID.list`：同一声明中采集到的标识符集合。
- `T.type`：类型编码（`i/r/c/b/s`）。

类型编码映射：

| 编码 | 类型关键字 |
| ---- | ---------- |
| `i`  | `integer`  |
| `r`  | `real`     |
| `c`  | `char`     |
| `b`  | `boolean`  |
| `s`  | `string`   |

---

## 1 程序定义

`〈程序〉 → program ID ; 〈分程序〉 .`

- 动作：`enter(program-id)`（程序名登记到符号表，`cat='p'`）

`〈分程序〉 → 〈说明部分〉〈复合语句〉`

- 动作：进入/退出作用域层级。

---

## 2 说明部分

`〈说明部分〉 → 〈说明语句〉〈说明部分〉 | ε`

`〈说明语句〉 → 〈变量说明〉 | 〈函数说明〉 | 〈过程说明〉`

---

## 3 变量说明

`〈变量说明〉 → var 〈变量定义表〉`

`〈变量定义表〉 → 〈变量定义〉 ; 〈变量定义表〉 | 〈变量定义〉 ;`

`〈变量定义〉 → 〈标识符表〉 : 〈类型〉`

- 动作：`for id in ID.list: synbl[id].cat='v'; synbl[id].typ=T.type`

`〈标识符表〉 → ID 〈标识符表尾〉`

- 动作：初始化 `ID.list = [ID]`

`〈标识符表尾〉 → , ID 〈标识符表尾〉 | ε`

- 动作：`ID.list.push(ID)`

---

## 4 函数说明

`〈函数说明〉 → function ID 〈形式参数〉 : 〈类型〉 ; 〈分程序〉 ;`

- 动作：
  - 函数名入符号表：`cat='f'`
  - 返回类型：`synbl[ID].typ = T.type`
  - 记录形参信息到 `PFINFL`

`〈形式参数〉 → ( 〈参数表〉 ) | ε`

`〈参数表〉 → 〈参数定义〉〈参数表尾〉`

`〈参数表尾〉 → ; 〈参数定义〉〈参数表尾〉 | ε`

`〈参数定义〉 → 〈值参数〉 | 〈变量参数〉`

`〈值参数〉 → 〈标识符表〉 : 〈类型〉`

- 动作：`for id in ID.list: synbl[id].cat='vf'; synbl[id].typ=T.type`

`〈变量参数〉 → var 〈标识符表〉 : 〈类型〉`

- 动作：`for id in ID.list: synbl[id].cat='vn'; synbl[id].typ=T.type`

---

## 5 过程说明

`〈过程说明〉 → procedure ID 〈形式参数〉 ; 〈分程序〉 ;`

- 动作：过程名入符号表（`cat='p'`），并记录形参信息。

---

## 6 复合语句

`〈复合语句〉 → begin 〈语句表〉 end`

`〈语句表〉 → 〈语句〉 ; 〈语句表〉 | ε`

---

## 7 语句定义

`〈语句〉 → ...`

### 赋值

`ID := 〈表达式〉`

- 动作：`emit(':=', E.place, '', ID.name)`

### 过程调用

`ID 〈调用后缀〉`

- 动作：
  - 对每个实参 `ai`：`emit('param', ai, '', '')`
  - `emit('call', ID.name, argc, '')`

### if-then-else

`if E then S1 else S2`

- 动作：
  - `i = emit('jfalse', E.place, '', '?')`
  - 翻译 `S1`
  - `j = emit('j', '', '', '?')`
  - `backpatch(i, nextquad)` 后翻译 `S2`
  - `backpatch(j, nextquad)`

`if E then S1`

- 动作：
  - `i = emit('jfalse', E.place, '', '?')`
  - 翻译 `S1`
  - `backpatch(i, nextquad)`

### while-do

`while E do S`

- 动作：
  - `begin = nextquad`
  - `i = emit('jfalse', E.place, '', '?')`
  - 翻译 `S`
  - `emit('j', '', '', begin)`
  - `backpatch(i, nextquad)`

---

## 8 调用后缀

`〈调用后缀〉 → ( 〈实参表〉 ) | ε`

- 动作：保存实参数组 `Args`（可空）。

---

## 9 实参表

`〈实参表〉 → 〈表达式〉〈实参表尾〉 | ε`

`〈实参表尾〉 → , 〈表达式〉〈实参表尾〉 | ε`

- 动作：按出现顺序收集 `Args`。

---

## 10 表达式（LR 规约语义）

`E → E1 || E2`

- `t=newtemp(); emit('||', E1.place, E2.place, t); E.place=t`

`E → E1 && E2`

- `t=newtemp(); emit('&&', E1.place, E2.place, t); E.place=t`

`E → !E1`

- `t=newtemp(); emit('!', E1.place, '', t); E.place=t`

`E → E1 relop E2`

- `t=newtemp(); emit(relop, E1.place, E2.place, t); E.place=t`

`E → E1 + E2 | E1 - E2 | E1 * E2 | E1 / E2`

- `t=newtemp(); emit(op, E1.place, E2.place, t); E.place=t`

`E → -E1`

- `t=newtemp(); emit('-', 0, E1.place, t); E.place=t`

`Factor → ID 〈调用后缀〉`

- 若 `〈调用后缀〉` 非空（函数调用）：
  - 逐个 `param`
  - `t=newtemp(); emit('call', ID.name, argc, t); Factor.place=t`
- 否则：`Factor.place = ID.name`

`Factor → INT | REAL | STRING | true | false`

- `Factor.place = literal`

`Factor → (E)`

- `Factor.place = E.place`

---

## 11 类型

`〈类型〉 → integer | real | char | boolean | string`

- 动作：映射到 `T.type ∈ {i, r, c, b, s}`，必要时在 `TYPEL` 中创建项。
