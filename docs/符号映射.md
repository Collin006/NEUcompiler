# 文法符号 → C++ 标识符映射

本文档定义 `docs/文法.md` 中每个非终结符在 `parser.cpp` 中的对应 C++ 函数名。

## 命名约定

- 中文非终结符 → 英文 PascalCase 函数名，统一前缀 `parse`
- 语法规则中的 `ε` 不产生独立函数，直接在上层函数中处理
- 终结符匹配使用 `matchKeyword` / `matchDelimiter` / `matchId` 等辅助方法

---

## §1 程序定义

| 文法符号 | C++ 函数 | 说明 |
|----------|----------|------|
| `〈程序〉` | `parseProgram()` | 入口：`program ID ; 〈分程序〉 .` |
| `〈分程序〉` | `parseSubProgram()` | `〈说明部分〉〈复合语句〉` |

## §2 说明部分

| 文法符号 | C++ 函数 | 说明 |
|----------|----------|------|
| `〈说明部分〉` | `parseDeclarationPart()` | 循环调用 `parseDeclarationStatement`，直到不再是声明 |
| `〈说明语句〉` | `parseDeclarationStatement()` | 分发到 var / function / procedure |

## §3 变量说明

| 文法符号 | C++ 函数 | 说明 |
|----------|----------|------|
| `〈变量说明〉` | `parseVariableDeclaration()` | `var 〈变量定义表〉` |
| `〈变量定义表〉` | `parseVariableDefinitionList()` | 循环：`〈变量定义〉 ;` |
| `〈变量定义〉` | `parseVariableDefinition()` | `〈标识符表〉 : 〈类型〉` |
| `〈标识符表〉` | `parseIdentifierList()` | `ID 〈标识符表尾〉` |
| `〈标识符表尾〉` | `parseIdentifierListTail()` | `, ID ...` 循环 |

## §4 函数说明

| 文法符号 | C++ 函数 | 说明 |
|----------|----------|------|
| `〈函数说明〉` | `parseFunctionDeclaration()` | `function ID (…) : type ; block ;` |
| `〈形式参数〉` | `parseFormalParameters()` | `( ... )` 或 ε |
| `〈参数表〉` | `parseParameterList()` | `〈参数定义〉〈参数表尾〉` |
| `〈参数表尾〉` | `parseParameterListTail()` | `; 〈参数定义〉 ...` |
| `〈参数定义〉` | `parseParameterDefinition()` | 分发到值参数 / 变量参数 |
| `〈值参数〉` | `parseValueParameter()` | `〈标识符表〉 : 〈类型〉` |
| `〈变量参数〉` | `parseVarParameter()` | `var 〈标识符表〉 : 〈类型〉` |

## §5 过程说明

| 文法符号 | C++ 函数 | 说明 |
|----------|----------|------|
| `〈过程说明〉` | `parseProcedureDeclaration()` | `procedure ID (…) ; block ;` |

## §6 复合语句

| 文法符号 | C++ 函数 | 说明 |
|----------|----------|------|
| `〈复合语句〉` | `parseCompoundStatement()` | `begin ... end` |
| `〈语句表〉` | `parseStatementList()` | `〈语句〉 ; ...` 循环 |

## §7 语句定义

| 文法符号 | C++ 函数 | 说明 |
|----------|----------|------|
| `〈语句〉` | `parseStatement()` | 根据首 token 分发 |
| `〈匹配语句〉` | 合并入 `parseStatement()` | 递归下降自然消解悬空 else |
| `〈开放语句〉` | 合并入 `parseStatement()` | 同上 |
| if 语句 | `parseIfStatement()` | 内部辅助：if-then-else |
| while 语句 | `parseWhileStatement()` | 内部辅助：while-do |
| 赋值/调用 | `parseAssignOrCallStatement()` | `ID := ...` 或 `ID(...)` |

## §8 调用后缀

| 文法符号 | C++ 函数 | 说明 |
|----------|----------|------|
| `〈调用后缀〉` | `parseCallSuffix()` | `(〈实参表〉)` 或 ε |

## §9 实参表

| 文法符号 | C++ 函数 | 说明 |
|----------|----------|------|
| `〈实参表〉` | `parseActualParameterList()` | `〈表达式〉 ...` 或 ε |
| `〈实参表尾〉` | `parseActualParameterListTail()` | `, 〈表达式〉 ...` |

## §10 表达式

| 文法符号 | C++ 函数 | 说明 |
|----------|----------|------|
| `〈表达式〉` | `parseExpression(stopTokens)` | 使用自动构建的 LR(1) 分析器，支持 stopTokens 截断 |

## §11 类型

| 文法符号 | C++ 函数 | 说明 |
|----------|----------|------|
| `〈类型〉` | `parseType()` | 匹配 integer / real / char / boolean / string |

## §12 运算符

运算符匹配由 `parseExpression` 内部处理，暂不设独立函数。

## 辅助方法

| 方法 | 功能 |
|------|------|
| `current()` / `peek(n)` | 获取当前 / 前瞻 token |
| `advance()` | 消耗当前 token 并返回 |
| `isAtEnd()` | 是否到达 token 序列末尾 |
| `checkKeyword(kw)` | 检查当前 token 是否为指定关键字 |
| `matchKeyword(kw)` | 匹配并消耗指定关键字 |
| `checkDelimiter(d)` | 检查当前 token 是否为指定界符 |
| `matchDelimiter(d)` | 匹配并消耗指定界符 |
| `checkId()` / `matchId()` | 检查 / 匹配标识符 |
| `isExpressionStart()` | 检查当前 token 能否开始一个表达式 |
| `synchronize()` | 恐慌模式错误恢复 |

## 日志方法

| 方法 | 功能 |
|------|------|
| `enterRule(name)` | 进入语法规则，缩进 +1 |
| `exitRule(name, ok)` | 退出语法规则，缩进 -1，标记 OK/FAIL |
| `logMatch(token)` | 记录一个 token 匹配 |
| `logInfo(msg)` | 记录一般信息 |
| `error(msg)` | 记录错误并设置错误标志 |

## 表达式分析表输出入口

| 方法 | 功能 |
|------|------|
| `Parser::getExpressionAnalysisDump(dump, error)` | 在语法分析前获取自动构建的表达式 SELECT 集、ACTION 表与 GOTO 表文本 |
