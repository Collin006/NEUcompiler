# Pascal 文法（修订版）

## 0 词法分析已提供的 Token

以下内容由词法分析器识别，语法分析阶段直接使用：

ID          标识符
INT         整数常量
REAL        实数常量
CHAR_CONST  字符常量
STRING      字符串字面量

关键字：

```
program var function procedure begin end if then else while do
integer real char boolean string true false
```

界符 / 运算符：

```
; , : . ( ) := + - * / > >= < <= = <> && || !
```

---

## 1 程序定义

```
〈程序〉 → program ID ; 〈分程序〉 .

〈分程序〉 → 〈说明部分〉〈复合语句〉
```

---

## 2 说明部分

```
〈说明部分〉 → 〈说明语句〉〈说明部分〉
             | ε

〈说明语句〉 → 〈变量说明〉
             | 〈函数说明〉
             | 〈过程说明〉
             | 〈类型说明〉
```

---

## 3 变量说明

> **修改**：分号由分隔符改为终止符，每条变量定义必须以 `;` 结尾。

```
〈变量说明〉 → var 〈变量定义表〉

〈变量定义表〉 → 〈变量定义〉 ; 〈变量定义表〉
              | 〈变量定义〉 ;

〈变量定义〉 → 〈标识符表〉 : 〈类型〉

〈标识符表〉 → ID 〈标识符表尾〉

〈标识符表尾〉 → , ID 〈标识符表尾〉
              | ε
```

---

## 4 函数说明

```
〈函数说明〉 → function ID 〈形式参数〉 : 〈类型〉 ; 〈分程序〉 ;

〈形式参数〉 → ( 〈参数表〉 )
            | ε

〈参数表〉 → 〈参数定义〉〈参数表尾〉

〈参数表尾〉 → ; 〈参数定义〉〈参数表尾〉
            | ε

〈参数定义〉 → 〈值参数〉
             | 〈变量参数〉

〈值参数〉 → 〈标识符表〉 : 〈类型〉

〈变量参数〉 → var 〈标识符表〉 : 〈类型〉
```

---

## 5 过程说明

```
〈过程说明〉 → procedure ID 〈形式参数〉 ; 〈分程序〉 ;
```

---

## 6 类型说明

> **新增**：支持 `type` 声明段，定义数组类型（`array[low..high] of type`）和记录类型（`record ... end`）。

```
〈类型说明〉 → type 〈类型定义表〉

〈类型定义表〉 → 〈类型定义〉 ; 〈类型定义表〉
              | 〈类型定义〉 ;

〈类型定义〉 → ID = 〈类型构造器〉

〈类型构造器〉 → array [ INT .. INT ] of 〈类型〉
               | record 〈字段表〉 end

〈字段表〉 → 〈字段〉 ; 〈字段表〉
          | 〈字段〉 ;

〈字段〉 → 〈标识符表〉 : 〈类型〉
```

---

## 7 复合语句

> **修改**：分号由分隔符改为终止符，每条语句必须以 `;` 结尾（`end` 前允许空语句表）。

```
〈复合语句〉 → begin 〈语句表〉 end

〈语句表〉 → 〈语句〉 ; 〈语句表〉
          | ε
```

---

## 8 语句定义

> **修改**：
> - 删除 `ε`（空语句不再合法）
> - 删除 `call` 关键字，过程调用统一为 `ID(...)` 或 `ID`
> - 拆分〈匹配语句〉/〈开放语句〉解决悬空 else

```
〈语句〉 → 〈匹配语句〉
        | 〈开放语句〉

〈匹配语句〉 → ID := 〈表达式〉
            | ID 〈调用后缀〉
            | begin 〈语句表〉 end
            | if 〈表达式〉 then 〈匹配语句〉 else 〈匹配语句〉
            | while 〈表达式〉 do 〈语句〉

〈开放语句〉 → if 〈表达式〉 then 〈语句〉
            | if 〈表达式〉 then 〈匹配语句〉 else 〈开放语句〉
```

---

## 9 调用后缀

> **说明**：`〈调用后缀〉` 在语句中出现表示过程调用，在表达式中出现表示函数调用（或变量引用）。

```
〈调用后缀〉 → ( 〈实参表〉 )
            | ε
```

---

## 10 实参表

```
〈实参表〉 → 〈表达式〉〈实参表尾〉
          | ε

〈实参表尾〉 → , 〈表达式〉〈实参表尾〉
            | ε
```

---

## 11 表达式（统一入口）

> **修改**：删除原有的 `〈表达式〉 → 〈布尔表达式〉 | 〈算术表达式〉` 二选一入口，
> 统一为单入口，通过优先级分层容纳算术、关系、布尔运算。
>
> 优先级（由低到高）：`||`  <  `&&`  <  `!`  <  关系  <  `+ -`  <  `* /`  <  一元 `- !`

```
〈表达式〉 → 〈布尔表达式〉

〈布尔表达式〉 → 〈布尔表达式〉 || 〈布尔项〉
              | 〈布尔项〉

〈布尔项〉 → 〈布尔项〉 && 〈布尔因子〉
          | 〈布尔因子〉

〈布尔因子〉 → ! 〈布尔因子〉
            | 〈关系表达式〉

〈关系表达式〉 → 〈算术表达式〉〈关系运算符〉〈算术表达式〉
              | 〈算术表达式〉

〈算术表达式〉 → 〈算术表达式〉 + 〈项〉
              | 〈算术表达式〉 - 〈项〉
              | 〈项〉

〈项〉 → 〈项〉 * 〈因子〉
      | 〈项〉 / 〈因子〉
      | 〈因子〉

〈因子〉 → ID 〈调用后缀〉
        | INT
        | REAL
        | CHAR_CONST
        | STRING
        | true
        | false
        | ( 〈表达式〉 )
        | - 〈因子〉
```

> **示例**：
> - `a + b` → 表达式 → ... → 关系表达式 → 算术表达式（唯一路径）
> - `a > b` → 表达式 → ... → 关系表达式 → 算术表达式 `>` 算术表达式
> - `a > b && c < d` → 布尔项 → 布尔项 `&&` 布尔因子 → (a>b) && (c<d)
> - `a := b + c` → 匹配语句 → ID `:=` 表达式（表达式 = b+c）

## 12 类型引用

> **修改**：新增 `string` 类型。支持类型名引用（用于变量声明的 `:` 后）。

```
〈类型引用〉 → integer
            | real
            | char
            | boolean
            | string
            | ID
```

## 13 运算符定义

```
〈加法运算符〉 → + | -

〈乘法运算符〉 → * | /

〈关系运算符〉 → >
              | >=
              | <
              | <=
              | =
              | <>
```

## 14 分析策略

外层结构使用递归下降：

```
program
var
function / procedure
begin … end
if … then … else
while … do
语句表
```

表达式部分使用 LR / SLR / 算符优先（单入口 `〈表达式〉`）：

```
表达式（含算术、关系、布尔，统一入口）
实参表达式
```

表达式分析器应支持 stopTokens：

```
if 条件：遇到 then 停止
while 条件：遇到 do 停止
实参：遇到 , 或 ) 停止
赋值：遇到 ; 或 end 停止
```

## 附录：修订说明

### v2.1（2026-05-16）

11. **【P2】新增类型说明段（§6）**：在 `〈说明语句〉` 中增加 `| 〈类型说明〉`。支持 `type` 声明段，包含数组类型构造器（`array[low..high] of type`）和记录类型构造器（`record field-list end`）。类型定义不生成四元式，仅填充 TYPEL/AINFL/RINFL 表。

12. **【P3】类型引用支持 ID（§12）**：`〈类型引用〉` 增加 `| ID` 备选，支持使用自定义类型名（如 `var arr: MyArray;`）。

13. **【P3】章节重新编号**：因新增 §6（类型说明），后续章节号整体 +1（§7–§14）。

### v2.0（2026-05-11）

1. **【P0】统一表达式入口（§10）**：删除 `〈表达式〉 → 〈布尔表达式〉 | 〈算术表达式〉` 二选一分支，统一为 `〈表达式〉 → 〈布尔表达式〉`。在 `〈关系表达式〉` 中新增 `| 〈算术表达式〉` 可选分支，使纯算术表达式也能合法归约到顶层。优先级从低到高：`||` < `&&` < `!` < 关系 < `+ -` < `* /` < 一元 `- !`。

2. **【P0】修复悬空 else（§7）**：拆分 `〈匹配语句〉`（if 必有 else）和 `〈开放语句〉`（if 可无 else），从语法层面强制 else 匹配最近未闭合的 if。

3. **【P1】删除语句空产生式（§7）**：移除 `〈语句〉 → ε`，空语句不再合法。

4. **【P1】去除 call 关键字（全文）**：遵循标准 Pascal，过程调用统一为 `ID(args)` 或 `ID`，不再使用 `call` 关键字。原 `〈标识符后续语句〉`（§8）和 `〈过程调用后续〉`（§9）合并为 `〈调用后缀〉`（新 §8）。

5. **【P2】分号由分隔符改为终止符（§3, §6）**：`〈变量定义表〉` 和 `〈语句表〉` 均改为 `... ; ... | ε` 形态，每条变量定义/语句必须以 `;` 结尾。

6. **【P2】新增 string 类型（§11）**：`〈类型〉` 增加 `string` 备选，支持字符串变量声明。

7. **【P2】新增 STRING 字面量（§10）**：`〈因子〉` 增加 `STRING` 备选，支持字符串常量在表达式中使用（如赋值右部）。

8. **【P3】true/false 纳入因子（§10）**：将布尔常量从仅嵌套在 `〈布尔因子〉` 改为同时出现在 `〈因子〉` 中，简化表达式归约路径。

9. **【P3】章节重新编号**：消除原文档 16→19 的编号跳跃，整理为连续 §0–§13。原 `ω₀`/`ω₁` 更名为 `〈加法运算符〉`/`〈乘法运算符〉`。

10. **【P3】更新 §0 关键字列表**：移除 `call`，新增 `string`，与文法规则保持一致。

### 已知局限

- **内置过程**（`writeln`、`readln`、`write`、`read`）在词法分析器中被归类为 KEYWORD 而非 ID，当前文法未为其提供专门的语法规则。如需支持，可在 `〈匹配语句〉` 中新增对应产生式，或调整词法分析器对内置过程的分类策略。
